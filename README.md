# Vampella: Speed Reader

A book reader and speed-reading trainer for Android: a library of your own books (EPUB, FB2, PDF, DOCX, ODT, RTF, TXT), network catalogs (OPDS), word flashes and a pacer, the Schulte table. No ads, no purchases, no accounts, no data collection.

**Privacy Policy:** [PRIVACY_POLICY.md](PRIVACY_POLICY.md)

# Вампелла: Скорочтение

Читалка книг и тренажёр скорочтения для Android: библиотека своих книг (EPUB, FB2, PDF, DOCX, ODT, RTF, TXT), сетевые каталоги (OPDS), вспышки слов и пейсер, таблица Шульте. Без рекламы, покупок, учётных записей и сбора данных.

**Политика конфиденциальности:** [PRIVACY_POLICY.md](PRIVACY_POLICY.md)
